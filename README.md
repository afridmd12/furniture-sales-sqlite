
# 🛍️ Sales Summary Analysis with SQLite and Python

This project demonstrates how to analyze a small sales dataset stored in SQLite using Python, Pandas, and Matplotlib — all inside Google Colab. It includes SQL queries for summarizing sales data and visualizations to help understand revenue trends.

---

## 📁 Project Structure

- `18fc0d17-c270-46d4-a062-0601d2362343.txt` — SQL file containing the schema and data for a furniture sales table.
- `sales_summary_colab.ipynb` — Jupyter Notebook ready for Google Colab, with all steps from loading data to visualization.
- `sales_data.db` — SQLite database created from the `.txt` file.
- `sales_chart.png` — Optional bar chart showing revenue by product (generated by the script).

---

### 2. Load Data into SQLite

```python
import sqlite3

# Read SQL script
with open("18fc0d17-c270-46d4-a062-0601d2362343.txt", "r") as file:
    sql_script = file.read()

# Connect to DB and execute
conn = sqlite3.connect("sales_data.db")
cursor = conn.cursor()
cursor.execute("DROP TABLE IF EXISTS sales")  # To avoid 'table already exists' error
cursor.executescript(sql_script)
conn.commit()
```

## 📊 SQL Queries + Python Visualizations

### 🪑 1. Sales Summary by Product
```sql
SELECT product, COUNT(*) AS total_qty, SUM(price) AS revenue
FROM sales
GROUP BY product
```

```python
df.plot(kind='bar', x='product', y='revenue')
```

---

### 🇺🇸 2. Sales in the United States
```sql
SELECT product, COUNT(*) AS qty, SUM(price) AS revenue 
FROM sales 
WHERE country = 'United States' 
GROUP BY product
```

---

### 📆 3. Revenue Over Time
```sql
SELECT substr(transaction_date, 1, 5) AS date, SUM(price) AS revenue 
FROM sales 
GROUP BY date 
ORDER BY date
```

```python
df.plot(kind='line', x='date', y='revenue')
```

---

### 🏭 4. Revenue by Supplier
```sql
SELECT supplier, COUNT(*) AS sales_count, SUM(price) AS revenue 
FROM sales 
GROUP BY supplier
```
